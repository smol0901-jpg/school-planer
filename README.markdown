# Школьный планер

Простое автономное PWA-приложение для школы.

## Возможности

- **Расписание** — уроки и кружки / доп. занятия по дням недели
- **Что взять** — чеклист вещей на выбранный день (уроки + кружки)
- **Дашборд** — визуальная неделя (график), свободные окна, текущий/следующий урок, кружки и вещи
- **Автобусы** — маршруты с временем «когда выходить»
- **Заметки** — текстовые + **голосовые** (запись с микрофона)
- **Профиль** — имя, класс, школа
- **Данные только локально** — localStorage
- **Экспорт / импорт JSON** — файл или вставка текстом (удобно из мессенджера / нейросети)
- **Поделиться выборочно** — выбрать что именно экспортировать
- **Пример данных** — кнопка «Загрузить пример»
- **Промпт для нейросети** — сгенерировать шаблон и импортировать готовый JSON
- **Тёмная тема**
- **Работает офлайн** (PWA)

## Перенос данных

1. Экспорт JSON → файл или копирование
2. На другом устройстве: Импорт JSON → файл **или вставка текста**
3. Можно делиться только частью данных (Профиль → «Поделиться / выборочно»)

## Структура JSON (кратко)

```json
{
  "profile": { "name": "", "className": "", "school": "", "notes": "" },
  "lessons": [ { "id": "...", "day": 0, "subject": "...", "start": "08:30", "end": "09:15", "room": "", "teacher": "", "items": [] } ],
  "clubs": [ { "id": "...", "day": 1, "name": "Робототехника", "start": "15:00", "end": "16:30", "place": "", "teacher": "", "items": [], "notes": "" } ],
  "buses": [ { "id": "...", "number": "42", "time": "07:40", "destination": "Школа", "walkMin": 7, "notes": "" } ],
  "notes": [ { "id": "...", "title": "", "body": "", "created": 0, "updated": 0 } ],
  "packChecks": {},
  "settings": { "theme": "light" }
}
```

`day`: 0 = Понедельник … 6 = Воскресенье.

## Технологии

Чистый HTML + CSS + JavaScript. Без фреймворков. Service Worker. localStorage.

## Лицензия

Свободно используй и модифицируй.
