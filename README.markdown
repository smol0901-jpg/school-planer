# Орбита — школьный планер

**Версия 3.8** · офлайн PWA · без сервера и аккаунтов

Умный планер для школы: расписание, канбан, автобусы, агент на русском, рюкзак, дневник, QR-обмен и импорт из Excel/JSON.

Данные хранятся **только на устройстве** (localStorage + IndexedDB).

---

## Демо (GitHub Pages)

После публикации репозитория открой:

```text
https://<username>.github.io/<repo>/
```

Например: `https://username.github.io/orbit-planner/`

> Если сайт в подпапке репозитория, в `manifest.json` и `sw.js` пути уже относительные (`./`) — отдельная настройка base path не нужна.

## Как выложить на GitHub Pages

### 1. Создай репозиторий

1. Новый репозиторий на GitHub (например `orbit-planner`).
2. Загрузи **содержимое** папки `orbit-planner` в корень репозитория  
   (чтобы `index.html` лежал в корне, не внутри вложенной папки).

```bash
cd orbit-planner
git init
git add .
git commit -m "Орбита v3.8 — школьный планер"
git branch -M main
git remote add origin https://github.com/<username>/orbit-planner.git
git push -u origin main
```

### 2. Включи Pages

1. **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` / folder `/ (root)`
4. Save

Через 1–2 минуты сайт будет по адресу  
`https://<username>.github.io/orbit-planner/`

### 3. Установка как приложение (PWA)

- **Android / Chrome:** «Установить приложение» или «На экран Домой»
- **iOS Safari:** Поделиться → На экран «Домой»

Работает офлайн после первого открытия.

## Отмена действий

В шапке кнопка **↩** — отменить последний шаг (урок, автобус, удаление…).  
Долгое нажатие (или ПКМ) — отменить до **5 шагов**. История до 15 состояний, только на устройстве.

Агент: `отмена`, `отмена 3`.

## Облако (опционально, не обязательно)

Основной режим — **офлайн**. Аккаунты/Supabase имеет смысл только если нужны:
- несколько детей у родителя с переключением профилей;
- доступ с разных устройств;
- супер-админ для поддержки (отдельный URL, не внутри планера).

На free-тарифе ~500 МБ на весь проект — без фото/видео в облаке хватит на тысячи текстовых профилей.  
Агента в облако **обучать не стоит** как обязательную фичу: обучение локально (IndexedDB) проще и приватнее.

## Возможности

| Раздел | Что умеет |
|--------|-----------|
| **Сегодня** | Таймлайн, ближайшие автобусы, «Я домой», графики недели |
| **Уроки** | Расписание по дням, предметы-чипы, пересечения запрещены |
| **Канбан** | Перетаскивание пальцем, замены ← → |
| **Рюкзак** | Что взять + чеклист по дням |
| **Автобус** | Откуда → куда, пересадки, время до остановки, без дублей |
| **Агент** | Команды на русском, сокращения (мат, физра…), обучение |
| **Задачи** | Домашка и цели |
| **Дневник** | Настроение и итог дня |
| **Заметки** | Текст + голос |
| **Профиль** | Люди, каникулы, QR, JSON/Excel, настройки, **Очистка** |

### Агент (примеры)

- `добавь` → выбор предмета → `пн 8:30`
- `мат` / `физра` / `русский добавь`
- `удали` → день / несколько дней / всю неделю
- `очисти расписание` · `очисти автобусы`
- `перенеси математику с пн на вт`
- `я домой` · `свободное время` · `что взять завтра`

### Импорт

Профиль → **Данные**:

- JSON (файл или текст)
- Excel `.xlsx` (шаблон в `templates/`)
- CSV
- Word-шаблон для ручного заполнения

### Очистка (безопасно)

Профиль → **Очистка** — отдельный блок:

- уроки / кружки / события / всё расписание  
- автобусы / дубли  
- домашка, заметки, дневник  
- люди, каникулы  
- память агента  
- **полный сброс**  

Только с подтверждением (для критичного — двойным).

## Формат данных (кратко)

```json
{
  "version": "3.8.0",
  "profile": { "name": "", "className": "", "school": "" },
  "lessons": [{ "day": 0, "subject": "Математика", "start": "08:30", "end": "09:10" }],
  "clubs": [],
  "buses": [{ "number": "518", "time": "07:25", "from": "…", "to": "…", "walkMin": 7 }],
  "homework": [],
  "events": [],
  "people": [],
  "holidays": [],
  "settings": {
    "lessonDuration": 40,
    "breakDuration": 10,
    "break15": 15,
    "longBreakDuration": 20
  }
}
```

`day`: **0 = понедельник … 6 = воскресенье**.

## Локальный запуск

Любой статический сервер из папки проекта:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Открой `http://localhost:8080`.  
Либо просто открой `index.html` в браузере (часть API камеры/PWA удобнее через http).
