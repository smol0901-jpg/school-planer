# Школьный планер

Простое автономное PWA-приложение для школы.

## Возможности

- **Расписание** — уроки по дням недели с временем, кабинетом, учителем и списком вещей
- **Что взять** — чеклист вещей на выбранный день (галочки сохраняются)
- **Сегодня** — быстрый обзор текущего дня и вещей
- **Автобусы** — маршруты с временем отправления и «сколько идти». Показывает, когда выходить
- **Заметки** — простая записная книжка с поиском
- **Профиль** — имя, класс, школа
- **Данные только локально** — всё хранится в localStorage устройства
- **Экспорт / импорт JSON** — можно перенести данные на другое устройство (файл **или просто вставить текст** JSON из мессенджера / нейросети)
- **Промпт для нейросети** — сгенерировать шаблон, вставить в ChatGPT / Claude / Grok, получить готовый JSON и импортировать (поддерживается вставка даже с ```json обёрткой)
- **Сейчас / следующий урок** — на вкладке «Сегодня» видно текущий урок и сколько осталось, либо через сколько следующий
- **Тёмная тема**
- **Работает офлайн** после первого открытия (PWA)

## Как установить

### На телефон / планшет (PWA)

1. Открой сайт на GitHub Pages (или локально через любой статический сервер)
2. В браузере (Chrome / Safari / Edge):
   - Android: «Добавить на главный экран» / «Установить приложение»
   - iOS Safari: Поделиться → «На экран Домой»
3. Приложение откроется в полноэкранном режиме и будет работать без интернета

### На ПК

Открой `index.html` или задеплой папку на GitHub Pages / Netlify / любой хостинг.

## Как задеплоить на GitHub Pages

1. Создай репозиторий
2. Загрузи все файлы из этой папки в корень (или в `/docs`)
3. Settings → Pages → Source: Deploy from branch → main / docs
4. Готово. Ссылка будет вида `https://username.github.io/repo-name/`

## Перенос данных между устройствами

1. **Экспорт JSON** → файл скачивается
2. Передай файл любым способом (Telegram, WhatsApp, Bluetooth, AirDrop, кабель, облако) **или просто скопируй содержимое файла**
3. На другом устройстве: **Импорт JSON** → можно:
   - выбрать файл `.json`
   - **или вставить текст JSON** прямо в поле (удобно, если прислали в мессенджере или получили от нейросети)

Bluetooth напрямую между браузерами для произвольных данных в PWA practically недоступен (ограничения iOS + Web Bluetooth только для BLE GATT). Передача файла или текста — самый надёжный способ.

## Структура данных (JSON)

```json
{
  "profile": { "name": "", "className": "", "school": "", "notes": "" },
  "lessons": [
    {
      "id": "abc",
      "day": 0,
      "subject": "Математика",
      "start": "08:30",
      "end": "09:15",
      "room": "305",
      "teacher": "",
      "items": ["тетрадь", "учебник"]
    }
  ],
  "buses": [
    {
      "id": "xyz",
      "number": "42",
      "time": "07:40",
      "destination": "Школа",
      "walkMin": 7,
      "notes": ""
    }
  ],
  "notes": [],
  "packChecks": {},
  "settings": { "theme": "light" }
}
```

`day`: 0 = Понедельник … 6 = Воскресенье.

## Технологии

Чистый HTML + CSS + JavaScript. Без фреймворков и сборки. Service Worker для офлайна. localStorage для данных.

## Лицензия

Свободно используй и модифицируй.
