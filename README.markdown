# Орбита — школьный планер

**Версия 4.3.2** · офлайн PWA · без сервера и аккаунтов

Умный планер: расписание, автобусы под уроки, агент с вкладками, контакты, SOS, обмен QR/файл, настройки и бренды.

Данные **только на устройстве** (localStorage + IndexedDB).

---

## Быстрый старт

1. Откройте `index.html` по адресу сайта (GitHub Pages) — так работают установка, офлайн и «Поделиться в Орбиту».
2. Или локально через любой static-server (не `file://` для SW/камеры).

```bash
# пример
npx serve .
```

## История версий 4.x

### 4.3.2 — мастер настройки нейросети
- Блок **«Мастер нейросети»** в Настройки → Агент
- Кнопка **Проверить подключение** — шаги: API вкл → провайдер → ключи → OAuth (Giga) → пробный chat
- Красным отмечен **конкретный** сбой (нет ключа, CORS, 401, неверный proxy…)
- **Быстро: GigaChat** — включает API, пресет, Scope, чистит ошибочный proxy

### 4.3.1 — фикс подключения GigaChat
- Proxy URL **не** должен быть `api.giga.chat` — только свой `https://…` прокси или **пусто**
- Если заполнены Client ID/Secret — режим GigaChat включается автоматически
- Понятная диагностика при «Load failed» / CORS
- Пресет «GigaChat (Сбер)» сбрасывает ошибочный proxy

### 4.3.0 — мультии провайдеры нейросетей
- **GigaChat (Сбер):** OAuth Client ID + Secret → Access token, chat completions на `api.giga.chat`
- **Grok (xAI), DeepSeek, Claude (Anthropic), OpenAI** — пресеты в Настройки → Агент
- **Другая** — любой OpenAI-совместимый endpoint
- Поля: Client ID / Secret / Authorization Key / Scope / Proxy URL (для CORS)
- Ключи **только в localStorage на устройстве**, в репозиторий не вшиваются
- Агент по-прежнему ждёт JSON `command` / `reply` от модели

> **Безопасность:** не публикуйте Client Secret и Authorization Key. При утечке перевыпустите ключ в Studio Сбера.

> **CORS:** запросы из браузера к `api.giga.chat` / `ngw.devices.sberbank.ru` часто блокируются. Для продакшена нужен свой Proxy URL (простой backend, который проксирует OAuth и chat).

### 4.2.2 — каталог skills в UI агента
- Команда **«помощь»** строится из `Orbit.actions.SKILLS` по категориям.
- Кнопки из помощи: сразу **Навыки** / **Быстрые**.
- **Рюкзак в чате:** галочки «взял» через агента (`togglePack` + отмена).
- Чипы подсказок подмешивают навыки из каталога.
- Надёжный разбор `ag:pack:день:вещь` в обработчике кнопок.

### 4.2.1 — агент-маршрутизатор LLM + документация
- LLM (если включён API) просит **JSON skill/command**, а не «свободный выдуманный ответ».
- Кнопка «Выполнить» для предложенной команды.
- Полный README с дорожной картой агента (этапы A–E).
- Полировка подсказок и каталога навыков.

### 4.2.0 — сильный агент (этапы A + B)
**Этап A — `Orbit.actions`:** единый слой действий
- Уроки: добавить / перенести / изменить / удалить / очистить день
- Кружки и автобусы: добавить / удалить
- ДЗ: добавить / отметить / список
- Люди и дни рождения
- Заметки, дневник, цели, напоминания
- Рюкзак: список и галочки
- Тема, «выходить за N мин», навигация по разделам
- История правок + `undoLast`

**Этап B — вкладки агента**
- **Чат** — ввод, live-подсказки, кнопки
- **Быстрые** — сетка команд
- **День** — сейчас, ДЗ, рюкзак, ДР
- **Правки** — последние изменения, отмена
- **Навыки** — каталог skills с примерами

**Поведение «я освободился»**
- Ближайший автобус **от текущего момента** (не от конца уроков)
- Предложение позвонить / SMS родным
- «Когда автобус домой» — по-прежнему от конца занятий, если день ещё идёт

**SOS**
- Вызов 112 только после **второго подтверждения** (защита от случайного нажатия)

## Агент: что умеет (кратко)

| Сказать | Результат |
|---------|-----------|
| `я освободился` | Ближайший автобус домой + кнопки родным |
| `когда выходить в школу` | Рейс к первому уроку |
| `что дальше` / `что задано` | Урок сейчас / список ДЗ |
| `добавь урок мат пн 8:30` | Урок через actions |
| `перенеси математику на среду` | Перенос |
| `добавь дз …` / `сделал дз …` | Домашка |
| `добавь кружок …` / `добавь автобус …` | Кружок / маршрут |
| `др мамы 12.03` / `дни рождения` | ДР |
| `заметка …` / `дневник …` / `цель …` | Записи |
| `открой уроки` / `тема светлая` | Навигация / тема |
| `отмена` | Отменить последнее изменение |
| `помощь` | Справка |

Вкладки агента = быстрый доступ к тем же действиям без набора текста.
