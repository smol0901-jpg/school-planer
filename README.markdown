# Орбита — Школьный планер v3

v3.1 — восстановлены все функции оригинала + улучшения.

Полностью обновлённый автономный PWA-планер для школы.

## Что нового (v3.2)

- **Канбан** — доска по дням: перенос уроков/кружков/событий стрелками (замены)
- **Длительность** — урок 40 мин, перемена 10, большая 20 (настраивается)
- **Агент** — полное управление: удаление по дню/предмету, переносы, очистка расписания и всего приложения

## Что нового (v3.1)

- **QR-обмен** — генерация QR по блокам (уроки / кружки / люди / каникулы / автобусы / домашка / вся база), считывание камерой и из файла
- **Выборочный шаринг** — поделиться любыми пунктами отдельно
- **Автобусы** — маршруты + «когда выходить»
- **Дневник** — итог дня, настроение, история
- **Люди и каникулы** — в профиле
- **Голосовые заметки** — запись с микрофона
- Всё из v3.0 (агент, графики, JSON-шаблоны) на месте

## Что нового (v3.0)

- **Ребрендинг** — название «Орбита», современный тёмный дизайн, акценты, градиенты
- **Агент Орбита** — встроенный помощник:
  - свободное время и окна
  - добавление уроков/кружков голосом/текстом
  - «что взять»
  - нагрузка недели
  - шаблоны JSON
- **Графики** — столбчатая диаграмма нагрузки по дням, визуальная сетка недели
- **Таймлайн дня** — уроки, кружки, автобусы на одной линии времени
- **Задачи** — домашка с приоритетами + цели с прогрессом
- **JSON-шаблоны**:
  - готовый файл `templates/schema-example.json`
  - текстовый промпт для нейросети
  - импорт из файла **или** вставка текста
- **Улучшенный рюкзак** — чеклист вещей по дням
- **Настройки** — тема, акцент, шрифт, скругление
- **Миграция** — автоматически подхватывает данные старого «Школьного планера»

## Возможности

| Раздел        | Описание                                      |
|---------------|-----------------------------------------------|
| Сегодня       | Герой-карточка, таймлайн, графики, ДЗ         |
| Расписание    | Уроки и кружки по дням                        |
| Рюкзак        | Что взять + галочки                           |
| Агент         | Чат-помощник                                  |

## Структура JSON

```json
{
  "version": "3.0.0",
  "profile": { "name": "", "className": "", "school": "", "notes": "" },
  "lessons": [{ "id": "", "day": 0, "subject": "", "start": "08:30", "end": "09:15", "room": "", "teacher": "", "items": [] }],
  "clubs": [{ "id": "", "day": 2, "name": "", "start": "15:00", "end": "16:30", "place": "", "teacher": "", "items": [], "notes": "" }],
  "buses": [{ "id": "", "number": "42", "time": "07:40", "destination": "Школа", "walkMin": 7 }],
  "homework": [{ "id": "", "subject": "", "title": "", "due": "YYYY-MM-DD", "done": false, "priority": "high|medium|low" }],
  "goals": [{ "id": "", "title": "", "deadline": "", "progress": 0, "notes": "" }],
  "notes": [{ "id": "", "title": "", "body": "", "created": 0, "updated": 0 }],
  "packChecks": {},
  "settings": { "theme": "dark", "accent": "violet" }
}
```

`day`: 0 = Понедельник … 6 = Воскресенье.

## Как пользоваться

1. Открой `index.html` в браузере (или установи как PWA).
2. Нажми **«Загрузить пример»** в Профиль → Данные.
3. Или импортируй свой JSON / попроси нейросеть по промпту.
4. Общайся с **Агентом** — он понимает команды на русском.
