# Орбита 4 — устройство

## Как расширять
- **Сменить название/логотип/палитру бренда** — `js/orbit/brand.js`, объект `BRANDS` (name, tag, agent, palette `d`/`l`, radius, font, логотип в `O.logo`). Иконки PWA — `icons/` (default-бренд).
- **Новый виджет главного экрана** — `js/orbit/dash.js`: функция `W.<id> = now => html`, запись в `O.WIDGETS`.
- **Новая команда агента** — `js/orbit/assistant.js`: `on(/regex/, (text, norm, now, match) => R('ответ', {cards, buttons}), 'имя')`. Изменения данных — через `change(текст, do, undo)` (подтверждение или «Отменить» по настройке автономности).
- **Логика автобусов** — `js/orbit/engine.js`: `planHome` (после освобождения), `planSchool` (к первому уроку), `nextBuses`. Покрыто тестом `node test.engine.js`-стилем (чистые функции).

## Данные
Автобус: `{number, dir:'school|home|other', from, to, walkMin, rideMin, days:[0..6] (пусто = каждый день), times:['07:40',…], time (= первый рейс, для старых экранов)}`. Контакт: `+phone, phone2, tg, email, address, fav, emergency`. Новые: `reminders[]`, настройки `brand, accentCustom, font, textScale, glass, motion, contrast, exitMin, arriveBefore, rideDefault, showBuses, notify*, sos*, agent*, widgets`.
Старые данные (3.x) открываются: миграция превращает автобусы в маршруты с одним рейсом.

## Честно об ограничениях
- **Bluetooth**: браузер не умеет отправлять файлы по Bluetooth напрямую. «Отправить…» открывает системное меню, где Bluetooth (Android), AirDrop (iOS/Mac), Nearby Share доступны, если ОС их поддерживает.
- **Звонок**: «в одно касание» = кнопка/ссылка `tel:`. Браузер не набирает сам без нажатия (защита). Агент показывает карточку с кнопкой «Позвонить».
- **Уведомления** работают, пока приложение открыто или установлено и не выгружено системой; гарантированные push требуют сервера.
- **Геопозиция SOS** отправляется SMS-ссылкой на карту только выбранному контакту и только по нажатию.
- Голосовой ввод — Web Speech API (Chrome/Edge/Safari; в Chrome распознавание делает облако браузера).
